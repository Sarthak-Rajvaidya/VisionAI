1. ultralytics — Object Detection (YOLO)

Used to detect and identify objects in images and videos using YOLO models.
- Detects people, cars, animals, etc.
- Draws bounding boxes around detected objects.
- Supports real-time object detection using a webcam.
Example: Detecting a person standing in front of a camera.


2. opencv-python — Image and Video Processing

OpenCV helps your program capture, process, and manipulate images and videos.
- Accesses a webcam.
- Reads images and video frames.
- Resizes images and converts color formats.
- Displays the processed video feed.
Example: Capturing live video from your laptop webcam


3. pyttsx3 — Text-to-Speech (TTS)

Converts written text into spoken audio, usually using your computer's installed speech engine.
- Speaks detected object names.
- Can work offline.
- Supports speech rate and voice settings.
Example: Your program says, “Person detected” aloud.

4. numpy — Numerical and Array Operations

NumPy provides efficient arrays and mathematical operations that are useful for processing image data.
- Stores and manipulates numerical arrays.
- Performs mathematical calculations.
- Helps process pixel values and image dimensions.
Example: Representing an image as a multidimensional array of pixel values
